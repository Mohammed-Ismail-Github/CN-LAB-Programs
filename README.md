# CN-LAB-Programs

## ACE R24 — Computer Networks Lab

This repository contains Computer Networks Lab programs based on the ACE Engineering College R24 syllabus.

The programs are being uploaded one by one according to the lab index as the course progresses.

The repository will be continuously updated with new programs, implementations, and practical exercises throughout the Computer Networks Lab.

---

## 📚 List of Experiments

### 1. Data Link Layer Framing

Implement the Data Link Layer framing methods:

- Character Count
- Character Stuffing
- Bit Stuffing

Programs:
- char_count.c
- char_stuffing.c
- bit_stuffing.c

Status: ✅ Completed

---

### 2. CRC

Write a program to compute CRC code for:

- CRC-12
- CRC-16
- CRC-CCITT

Program:
- crc.c

Status: ✅ Completed

---

### 3. Sliding Window and Go-Back-N

Develop a simple Data Link Layer that performs:

- Flow control using the Sliding Window Protocol
- Loss recovery using the Go-Back-N mechanism

Program:
- gobackN.c

Status: ✅ Completed

---

### 4. Dijkstra's Algorithm

Implement Dijkstra's algorithm to compute the shortest path through a network.

Status: ⏳ Upcoming

---

### 5. Broadcast Tree

Take an example subnet of hosts and obtain a broadcast tree for the subnet.

Status: ⏳ Upcoming

---

### 6. Distance Vector Routing

Implement the Distance Vector Routing algorithm for obtaining routing tables at each node.

Status: ⏳ Upcoming

---

### 7. Data Encryption and Decryption

Implement:

- Data Encryption
- Data Decryption

Status: ⏳ Upcoming

---

### 8. Leaky Bucket Algorithm

Write a program for congestion control using the Leaky Bucket algorithm.

Status: ⏳ Upcoming

---

### 9. Frame Sorting

Write a program for frame sorting techniques used in buffers.

Status: ⏳ Upcoming
